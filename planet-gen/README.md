# 低多边形星球生成器（可复现）

纯前端（原生 WebGL + ES Modules，无第三方依赖）的程序化星球生成器。

## 运行

```bash
cd planet-gen
python3 -m http.server 8764
# 浏览器打开 http://localhost:8764/index.html
```

## 功能

- **可旋转低多边形星球**：icosphere（5120 面）扁平着色，固定方向光，旋转时明暗连续；拖拽旋转、自动旋转速度可调。
- **地形**：seeded 3D 值噪声 fBm → 海洋/沙滩/草地/森林/岩石/雪原；`|y| > 极冠阈值` → 极冠。
- **云带**：独立噪声 + 纬度带调制，云层半径 `1+cloudOffset` 始终大于大气半径 `1+atmoOffset`（自动修正），云缓慢差速自转。
- **Seed 切换**：Seed A/B 预设、任意 seed 输入、随机 seed；同 seed 布局哈希完全一致。
- **显式重新生成**：「🔄 重新生成」强制全量重算并校验哈希不变。
- **截图**：「📷 截图」下载 PNG。
- **参数保存/载入**：JSON 含 params + 障碍 + 目标 + 布局哈希；载入后重算并比对哈希一致性。
- **增量重算**：星球分为 320 个区块，每区块有独立缓存键。改极冠只重算极区区块，改云参数只重算云层（地表 0 重算），障碍只重算其影响半径内的区块。
- **校验**：场景边界（半径范围/单位向量/层序）、关键对象不重叠（最小角距）、目标可达性（陆地 BFS 连通）、可复现性（独立实例哈希一致）。
- **障碍**：「🚧 添加障碍」后点击球面，障碍落海；若导致路线断开，状态栏明确指出阻断位置（障碍 id、区块、经纬度）。
- **移动目标**：「🎯 移动目标」后点击新位置，最近目标被移动；仅新旧所在区块哈希变化，其余区块坐标与哈希保持不变。

## 状态面板

实时显示：seed、目标数量、规则摘要（全部生成参数）、布局哈希、
本次重算区块数/云层是否重算、路线连通状态与阻断位置。

## 测试

```bash
node test/verify.test.mjs
```

26 项断言：双 seed 全校验、seed 切换布局变化、显式重生成哈希不变、
参数增量重算、单对象修改区域隔离、障碍阻断报告、保存/载入哈希一致、云层在大气上方。

## 文件结构

- `js/rng.js` — mulberry32、FNV-1a 哈希、稳定序列化
- `js/noise.js` — seeded 3D 值噪声 + fBm
- `js/geometry.js` — icosphere、区块划分（320 块）、面邻接
- `js/planet.js` — 生成核心：分块缓存、目标放置、BFS 路线、障碍、哈希
- `js/verify.js` — 边界/不重叠/可达性/可复现校验
- `js/render.js` — WebGL 渲染（地表/大气/云/标记/路线）
- `js/main.js` — UI 交互
