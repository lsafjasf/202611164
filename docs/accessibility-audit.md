# 无障碍检查摘要 / Accessibility Audit Summary

生成日期：2026-11-16
测试方式：Playwright Chromium 自动化（`node test/run-tests.mjs`）+ 应用内三组自检（点击「运行自检」）
结果：Playwright 22/22 通过；应用内自检 21/21 通过；无运行时控制台错误。

## 一、已验证的操作路径

| 功能 | 键盘路径 | 鼠标路径 | 触屏路径 | 读屏/焦点反馈 |
| --- | --- | --- | --- | --- |
| 添加图形 | Tab 到「添加矩形/圆形/文字」按钮后 Enter | 点击工具栏按钮 | 点按工具栏按钮 | 按钮具备可读文案，live region 公告「已添加 {type}」 |
| 选中图形 | Tab 聚焦画布后方向键所在图形 | `mousedown` 命中测试 | `touchstart` 命中测试 | `#layer-info` 公告「已选中 {类型} (id)」，画布显示虚线焦点框 |
| 移动图形 | 方向键步进 5px，Shift+方向键 20px | 按住拖拽 | 单指拖拽（`touch-action: none`） | live region 公告「已移动到 x=, y=」 |
| 删除图形 | Delete/Backspace | 点击「删除所选」 | 点按「删除所选」 | 公告「已删除所选图形」，焦点保留在画布 |
| 语言切换 | Tab 到语言下拉框，方向键选择 | 点击下拉选择 | 点按下拉选择 | 全站 `data-i18n` 文案与 `<html lang>` 同步更新，图形不丢失 |
| 文字编辑 | Tab 到文本域直接输入 | 点击文本域输入 | 点按文本域输入 | 标签关联 `<label for>`，输入实时重排 |
| 导出 | Tab 到 PNG/SVG 按钮后 Enter | 点击导出按钮 | 点按导出按钮 | 公告「已导出 {格式}，编辑状态已保留」 |
| 撤销/重做 | Tab 到按钮后 Enter，按钮禁用态可感知 | 点击 | 点按 | 禁用状态随历史栈更新 |
| 运行自检 | Tab 到「运行自检」后 Enter | 点击 | 点按 | 结果写入 `aria-live` 区域，逐条显示 PASS 或失败原因 |

## 二、焦点与读屏机制

- 画布为 `tabindex="0"` + `role="application"`，`aria-label` 随语言切换。
- 全局 `#live-region` 使用 `role="status"` 与 `aria-live="polite"`，所有增删移动、导出、错误恢复均发出公告。
- `#layer-info` 以 `aria-live="polite"` 播报当前选中图层。
- 所有交互控件具备可见焦点环（`outline: 3px solid`），按钮最小高度 40px，满足触屏目标尺寸。
- 自检结果区域使用 `aria-live="polite"`，汇总文案明确给出 `通过数/总数 (百分比)`，失败项给出名称与原因，不使用笼统提示。

## 三、失败与恢复路径验证

| 场景 | 触发方式 | 验证结果 |
| --- | --- | --- |
| localStorage 写入失败 | 自检将 `store.forceFailure = true` 后调用持久化 | 返回 `false`，公告存储不可用，内存编辑不中断 |
| 导出编码器异常 | 模拟 `canvas.toDataURL` 抛错 | 异常被捕获，公告「导出失败：{原因}」，播放错误音效，工程状态不变 |
| 导出前状态保留 | 每次导出先写 `pre-export-snapshot/v1` 快照 | 快照存在；「恢复快照」可回到导出前状态并公告 |
| 刷新/重载恢复 | Playwright `page.reload()` 与新触屏上下文（共享 storageState） | 图形数量、语言、导出历史与刷新前一致，未被静默重置 |
| 超长拉丁词 | 宽度小于单词的文本框 | 按字符拆分，不产生越界 |
| 孤字/孤词 | 中英数混排长文本窄框排版 | 末行至少两个排版 token，必要时从上一行借词重排 |
| 空画布命中测试 | 对空图形数组做命中 | 返回 `null`，不抛异常 |
| 圆形边角误命中 | 点击圆形外接框角落 | 椭圆方程判定排除，返回未命中 |

## 四、三组可重复测试清单

- 默认用例（7 项）：混合文本换行、无空行、命中测试、SVG/PNG 载荷、撤销、重做。
- 边界用例（7 项）：窄框多行、孤字消除、超长拉丁词拆分、空文本、数字组换行、空画布命中、圆形边角。
- 错误恢复用例（7 项）：存储失败检测、失败后继续编辑、快照恢复、状态一致性、重载持久化、导出错误抛出与消息保留。

## 五、残留风险

- 无头环境未安装完整系统字体，CJK 字形度量与用户本机可能有像素级差异；换行策略基于 Canvas 实测宽度，字体变化时仍成立。
- Web Audio 在首次用户手势前创建会被浏览器策略挂起，代码在每次播报时调用 `resume()`，无音频设备时静默降级，不阻塞功能。
