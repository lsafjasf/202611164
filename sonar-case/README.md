# 潜航声呐调查案

纯前端单页应用：潜航器只能凭主动声呐回波与水听器海流声像推断暗礁、信标频段与海流方向，
回收三个信标并返回母舰后提交结论。

## 运行

ES Module 需要通过 HTTP 访问（直接双击 `index.html` 会被浏览器模块策略拦截）：

```bash
cd sonar-case
python3 -m http.server 8942
# 浏览器打开 http://127.0.0.1:8942/index.html
```

## 玩法与规则

- 10x10 海图，母舰 `H` 在左上角；调查阶段不绘制暗礁、信标与海流，结论提交前无法看到真实答案。
- 主动声呐扫描（-4 能源）：回波按传播时延排列，扫描次数越多，本底噪声越高、非目标杂波越多。
- 水听器监听（-3 能源）：给出最近信标的测得频率（带 ±2% 误差）与海流左右舷声像、湍流强度。
- 移动 -2 能源，撞暗礁额外 -8；错误暗礁标记固定 -10 能源，正确标记不扣分。
- 收集齐 3 个信标并回到母舰即满足任务成功条件；能源耗尽强制失败。
- 按钮：开始、暂停/继续、同 seed 重开、提交结论；支持 WASD/方向键移动与海图点选标记。

## 确定性与防剧透

- `js/rng.js` 使用种子化 PRNG；地图由 `seed::map` 派生，每个格子的扫描/监听线索由
  `seed#类型@x,y` 派生，与玩家操作历史无关。同一 seed 重开，线索顺序、数值、惩罚完全一致。
- 调查阶段 UI 只使用 `publicState()`，其中深拷贝删除了 `map`、所有 `truth` 字段与标记对错，
  测试已断言公开数据中不存在 `reefs/beacons/current/truth`。
- 所有声音由 Web Audio 实时合成（脉冲、回波、信标音调、滤波海流噪声），无任何音频文件；
  重播只读取已保存的线索描述符重新合成，不写日志、不改逻辑时间或能源。
- 暂停仅切换状态并 `suspend()` AudioContext，引擎动作在暂停时一律拒绝，线索内容不变。

## 结算

提交后揭示真实海图，表格逐行并列「判断维度 / 你的推断 / 真实参数 / 对应声源·时间·频段证据 / 结果」，
错误结论按具体维度提示：暗礁`方位`或`距离`、信标`频段`、`海流方向`。

## 验证

```bash
node test/engine.test.js        # 8 项纯逻辑测试
```

覆盖：同 seed 线索完全复现、公开状态无真相泄露、噪音/杂波单调递增、错误标记固定扣能、
一次全对结论、一次含具体错误维度的错误结论、暂停冻结与重播不变。

浏览器端自检（需先起静态服务）：

- `test/smoke.html`：模块级端到端断言
- `test/ui-flow.html`：驱动真实页面按钮的 11 项 UI 流程断言（含同 seed 重开对比）

## 目录

- `js/rng.js` 种子化随机
- `js/config.js` 固定规则、频段与惩罚常量
- `js/engine.js` 纯逻辑引擎（地图、动作、线索、判定、脱敏）
- `js/audio.js` Web Audio 实时合成
- `js/render.js` Canvas 海图、波形、资源仪表
- `js/main.js` UI 绑定与结算渲染
